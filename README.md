# Credit Card Dashboard
A credit card customer and transaction analysis dashboard exploring
customer demographics, transaction behavior, and overall performance.

## Dashboard
[View the Interactive Dashboard](https://datastudio.google.com/s/nIYi2lUR6Hw)

## Tools
Google Looker Studio

## Dataset
The dataset contains dummy credit card customer and transaction data
from a company in the United States.
